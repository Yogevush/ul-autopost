# פרסום אוטומטי, יוניק הרצאות

מפרסם לאינסטגרם `unique.lectures` ולדף הפייסבוק "יוניק הרצאות ומופעים", כל פריט לשתי הפלטפורמות, החל מ-20:00 שעון ישראל.
רץ על שרתי גיטהאב. לא תלוי במחשב, בדפדפן או בקלוד.

## לוח השידורים

נקבע ב-`content/schedule.json`, אפשר לשנות בלי לגעת בקוד.

| יום | מה יוצא |
|---|---|
| ראשון | ריל |
| שני | פוסט (קרוסלה, ואם אין בתור אז תמונה) |
| שלישי | כלום |
| רביעי | ריל |
| חמישי | פוסט (קרוסלה, ואם אין בתור אז תמונה) |
| שישי ושבת | כלום |

ארבעה פריטים בשבוע: שני רילים ושתי קרוסלות. הריל הוא מה ששתי הפלטפורמות מפיצות למי שלא עוקב,
והקרוסלה היא הפורמט עם המעורבות הגבוהה ביותר לחשבונות קטנים. תמונה בודדת היא הפורמט החלש ביותר בנתונים,
ולכן היא רק גיבוי כשאין קרוסלה בתור.

סוגי משבצת אפשריים בלוח: `reel`, `post`, `carousel`, `image`, או `null` ליום בלי פרסום.
אם אין בתור פריט מהסוג שהלוח מבקש, יוצא פריט מסוג אחר (עדיף משהו מאשר כלום) ונפתח דיווח במאגר.

## חלון פרסום ואיחורים של גיטהאב

גיטהאב מאחר בהפעלת משימות מתוזמנות, לפעמים בשעות, בעיקר בתחילת שעה עגולה.
לכן המשימה מתעוררת תשע פעמים בערב, בדקות לא עגולות (17:07 עד 21:07 לפי גריניץ'),
והסקריפט מפרסם רק בתוך חלון הפרסום בישראל: מ-20:00 ובמשך `window_hours` שעות (ברירת מחדל 4).
ריצה שמגיעה לפני החלון יוצאת בשקט, ריצה שמגיעה אחרי שכבר פורסם היום יוצאת בשקט.
המעבר בין שעון קיץ לחורף מטופל לבד.

חגורה שנייה: לפני כל פרסום נבדק ב-`state/published.json` אם כבר יצא פוסט היום.
גם הרצה ידנית חוזרת לא תוציא שני פוסטים באותו יום.

## מדדים

פעם ביום (בריצה הראשונה שבתוך החלון) נשמרת ב-`state/metrics.json` תמונת מצב:
מספר העוקבים באינסטגרם ובפייסבוק, ולכל פוסט מהשבועות האחרונים: חשיפה, צפיות, לייקים, תגובות, שמירות ושיתופים.
משם אפשר לראות את הצמיחה לאורך זמן בלי להיכנס לשום לוח בקרה. כישלון באיסוף המדדים לא עוצר פרסום.

## מבנה

| נתיב | מה זה |
|---|---|
| `content/queue.json` | תור התוכן. הפריט הראשון שמתאים למשבצת של היום הוא זה שיוצא |
| `content/schedule.json` | לוח השידורים, השעה והחלון |
| `images/` | תמונות. ג'ייפג, 1080 על 1350. שקופיות של קרוסלה הן קבצים נפרדים |
| `videos/` | רילים. אמ-פי-4, 1080 על 1920 |
| `state/published.json` | מה כבר פורסם. מתעדכן ונדחף לבד |
| `state/metrics.json` | עוקבים וביצועים לאורך זמן. מתעדכן ונדחף לבד |
| `publish.py` | הפרסום עצמו |
| `tools/` | כלי הבנייה של התמונות, הקרוסלות והרילים. רצים בענן של קלוד, לא כאן |

### פריט בתור

```json
{
  "id": "car-01-choose-lecture",
  "type": "carousel",
  "files": ["car-01-choose-lecture-1.jpg", "car-01-choose-lecture-2.jpg"],
  "caption_instagram": "...",
  "caption_facebook": "...",
  "collaborators": ["שם_משתמש_באינסטגרם"],
  "hold": false
}
```

`type` הוא `image` (עם `file`), `carousel` (עם `files`, 2 עד 10) או `reel` (עם `file`).
`collaborators` (לא חובה): עד שלושה שמות משתמש באינסטגרם שמוזמנים כשותפים לפוסט.
שותף שמאשר מקבל את הפוסט גם בפרופיל שלו, ולכן גם העוקבים שלו רואים אותו.
זה הכלי החזק ביותר לחשבון עם מעט עוקבים: מרצה שמופיע בפוסט מביא את הקהל שלו.
`hold: true` משאיר פריט בתור בלי לפרסם אותו.

## הדף וחשבון האינסטגרם

הדף הוא **יוניק הרצאות ומופעים**, מזהה `336797430024031`, ומחובר אליו חשבון האינסטגרם
`unique.lectures`, מזהה `17841414158998473`.

שים לב לנקודה שעלתה בהקמה: הדף הזה לא מוחזר בכלל בקריאה `me/accounts`, כנראה בגלל
צורת הבעלות עליו במטא, ולכן הוא גם לא מופיע ברשימת הדפים בכלי של מטא. הפתרון:
מזהה הדף רשום מפורשות בשדה `page_id` בקובץ `content/schedule.json`, והסקריפט פונה
אליו ישירות. אם הדף יוחלף אי פעם, מעדכנים את השדה הזה ותו לא.

## הסוד היחיד

בהגדרות המאגר: Settings, Secrets and variables, Actions, New repository secret.

שם: `META_TOKEN`

הערך: אסימון גישה של דף הפייסבוק. אסימון כזה לא פג תוקף.
בלי הסוד הזה כל ריצה נכשלת מיד ושום דבר לא מתפרסם.

### איך משיגים אותו, פעם אחת

1. נכנסים ל-developers.facebook.com עם החשבון שמנהל את הדף.
2. My Apps, Create App, סוג Business.
3. מוסיפים לאפליקציה שני מוצרים: Facebook Login ו-Instagram.
4. נכנסים ל-Graph API Explorer, בוחרים את האפליקציה, ומבקשים אסימון משתמש עם ההרשאות:
   `pages_show_list`, `pages_read_engagement`, `pages_manage_posts`, `instagram_basic`, `instagram_content_publish`, `instagram_manage_insights`
5. מדביקים את האסימון ב-Access Token Debugger ולוחצים Extend Access Token.
6. חוזרים ל-Graph API Explorer עם האסימון הארוך, ושולחים בקשה ל-`336797430024031?fields=access_token`.
   הערך שחוזר הוא אסימון הדף, והוא לא פג. אותו שמים בסוד.
   (לא `me/accounts`, כי הדף הזה לא מופיע שם.)

האפליקציה נשארת במצב פיתוח. לא נדרש אישור אפליקציה כדי לפרסם לחשבון שאתה מנהל.
אם ריל של פייסבוק נכשל (למשל בגלל הרשאה חסרה), הסקריפט מפרסם אותו כווידאו רגיל בדף ולא מוותר.

## בדיקה ידנית

Actions, post, Run workflow. עם force מסומן זה מפרסם מיד, בלי לחכות לחלון, מהסוג שבוחרים.

## בניית תוכן חדש

```
npm install @fontsource/heebo
python3 tools/make_image.py    tools/scripts/<שם>.json images/<שם>.jpg
python3 tools/make_carousel.py tools/scripts/<שם>.json images/
python3 tools/make_reel.py     tools/scripts/<שם>.json videos/<שם>.mp4
```

הכלים בודקים בעצמם שהפלט עומד בדרישות אינסטגרם ונכשלים אם לא.
`make_carousel.py` מדפיס בסוף את הרשומה שמכניסים לתור.

## התראות

כשנשארים שלושה פריטים מסוג מסוים, נפתח דיווח במאגר.
כשהתור ריק, ההרצה נכשלת וגיטהאב שולח מייל.

## שתי הערות

התמונות והכיתובים כאן גלויים לציבור. זה בכוונה, משם אינסטגרם מושכת את הקבצים.
שום אסימון וסוד לא נמצאים בקוד, רק בהגדרות הסודות של גיטהאב.

הרילים מצטברים בהיסטוריית המאגר. בערך 10 מגה לריל.
פעם בשנה כדאי לפתוח מאגר נקי כדי שלא יתנפח.
